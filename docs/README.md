## Organization

- `project/` contains project-level direction, standards, rules, and terminology.
- `brand/` contains strategic brand architecture and approved brand specifications.
- `architecture/` describes system responsibilities, boundaries, and dependencies.
- `specs/` defines functional behavior and acceptance criteria.
- `ux/` and `ui/` contain experience and interface documentation.
- `design-system/` contains reusable visual and interaction standards.
- `data/`, `api/`, and `database/` describe information and integration concerns.
- `development/` and `testing/` contain engineering practices and quality guidance.
- `adr/` records architecture decisions.

## Placement Guidelines

Use the narrowest applicable section. Link related documents instead of duplicating content, and follow the documentation standard when adding or updating files.
